| Колір | HEX | Використання |

### Правила використання кольорів

- Велика кількість кольорів бренду обумовлена різними профілями політехніки
- **Необов'язково** використовувати всі кольори в одному дизайні
- Класично основними кольорами виступають **синій або зелений**
- Акцентними кольорами є **червоний або помаранчевий**
- Керуйтесь гармонійними поєднаннями

## 6. Правила використання логотипів

### Фон

| Дозволено | Заборонено |
|-----------|------------|
| Білий фон | Фон, що зливається з логотипом |
| Світлі відтінки сірого | Фотографії, що пересікаються з логотипом |
| Темний фон (білий варіант лого) | Занадто темний або яскравий фон для кольорового лого |

### Вільний простір (Clear space)

Однаково-широкий простір навколо логотипу повинен **обов'язково** залишатися вільним. Це правило діє при компонуванні з іншими логотипами чи зображеннями.

```
    ┌──────────────────────────────┐
    │                              │
    │   ┌──────────────────────┐   │
    │   │                      │   │
    │   │      ЛОГОТИП         │   │
    │   │                      │   │
    │   └──────────────────────┘   │
    │                              │
    └──────────────────────────────┘
         ↑ Вільна зона (clear space)
```

### Модифікації

> Якщо використання логотипу неможливе без його зміни (наприклад, друк брендованих матеріалів), **ОБОВ'ЯЗКОВО** погодити з відділом маркетингу та зв'язків з громадськістю Житомирської політехніки.

## 10. Застосування у проекті PDF Validator

### Як бренд застосовується в проекті

PDF Validator — це інструмент валідації дипломних робіт, створений у контексті Житомирської політехніки. Проект використовує бренд-систему університету для візуальної ідентичності.

### Рекомендації для UI

| Елемент | Рекомендація |
|---------|--------------|
| **Основний колір** | `#224A98` (синій) — заголовки, навігація |
| **Акцент** | `#E53E23` (червоний) — помилки валідації, alerts |
| **Успіх** | `#4CAD3B` (зелений) — success states |
| **Попередження** | `#EE781C` (помаранчевий) — warnings |
| **Шрифт** | Montserrat (Regular/Bold) |
| **Фон footer** | `#004D85` |

### Де взяти ресурси

Всі офіційні ресурси бренду доступні на: **[media.ztu.edu.ua](https://media.ztu.edu.ua/)**

Локальні асети проекту зберігаються в: `docs/brand/assets/`

### Правила для розробників

1. Використовуйте **тільки офіційні кольори** з палітри вище
2. Шрифт — **Montserrat** (Regular для тексту, Bold для заголовків)
3. При використанні логотипу дотримуйтесь правил clear space
4. Скорочена назва — **Житомирська політехніка** (без лапок, мала "п")
5. Будь-які зміни до логотипу погоджуються з відділом маркетингу
