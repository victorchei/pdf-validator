# Звіт з доступності (Accessibility Report)

## WCAG Контрастність кольорів

### Стандарти WCAG 2.1 AA

- **Звичайний текст**: мінімум 4.5:1
- **Великий текст** (18pt+ або 14pt+ bold): мінімум 3:1
- **Елементи UI**: мінімум 3:1

1. **Green (#4CAD3B)**: Використовувати лише для:
   - Великих заголовків

2. **Orange (#EE781C)**: Використовувати лише для:
   - Великих заголовків

## Поточний стан проекту

У поточній реалізації:
